# Device Performance & Battery Analysis

A Python project focused on analyzing battery consumption
and device performance measurements.

## Overview

The project aims to process device measurements, calculate
battery consumption statistics, and identify patterns in
device performance.

Currently under development.

## Current Features

- Read battery measurements from a CSV file
- Extract battery levels from individual measurements
- Calculate total battery percentage-point drop
- Display basic analysis results in the terminal

## Technologies

- Python 3
- CSV (Python standard library)

## How to Run

1. Clone the repository.
2. Open the project directory.
3. Run:

```bash
python main.py
```

## Dataset

The current dataset contains synthetic battery measurements
used for development and testing. It does not represent
real Android device telemetry.
